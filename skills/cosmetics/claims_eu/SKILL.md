# EU Cosmetic Claim Substantiation

## Regulatory framework

- **Regulation (EC) No 1223/2009** — the Cosmetics Regulation. Defines what
  a cosmetic product is, safety requirements, and labelling obligations.
- **Commission Regulation (EU) No 655/2013** — "Common Criteria" for cosmetic
  claims. All claims must be:
  1. **Legal** (compliant with regulations).
  2. **Truthful** (substantiated by evidence).
  3. **Evidenced** (adequate and verifiable studies or tests).
  4. **Honest** (not misleading).
  5. **Fair** (no denigration of competitors).
  6. **Informed decision-making** (consumer can make a free choice).

## Claim categories and evidence requirements

### Instrumental claims ("clinically proven", "measured improvement")

| Requirement                  | Detail                                        |
|------------------------------|-----------------------------------------------|
| Study design                 | Controlled, pre/post at minimum, ideally RCT  |
| Sample size                  | ≥ 20 subjects per group, power ≥ 80%          |
| Measurement instrument       | Validated (e.g. Corneometer® for hydration)   |
| Statistical analysis         | Pre-specified primary endpoint, multiplicity   |
| Effect size                  | Must be perceptible/relevant (practical threshold) |
| Duration                     | Matches the claim ("in 28 days" → D28 data)   |
| Wording                      | Must reference instrument, population, timepoint |
| Forbidden                    | "Medical", "treats", "cures", "drug-like"      |

### Consumer perception claims ("consumers reported smoother skin")

| Requirement                  | Detail                                        |
|------------------------------|-----------------------------------------------|
| Panel                        | Representative, ≥ 50 consumers (ISO 11930)    |
| Questionnaire                | Validated, Likert or similar                  |
| Reporting                    | Top-2-box % with 95% CI (Wilson)              |
| Wording                      | MUST start with "consumers reported / perceived" |
| Forbidden                    | "clinically proven", "scientifically measured" |

### Safety / tolerance claims ("hypoallergenic", "tested on sensitive skin")

| Requirement                  | Detail                                        |
|------------------------------|-----------------------------------------------|
| Dermatological evaluation    | Patch test and/or ROAT                        |
| AE reporting                 | Complete, with severity grading               |
| Population                   | Must include sensitive-skin subjects if claimed |
| Wording                      | Must specify test conditions and population   |
| Forbidden                    | "100% safe", "no side effects"                |

### Equivalence / Non-inferiority claims

| Requirement                  | Detail                                        |
|------------------------------|-----------------------------------------------|
| Margin                       | Pre-specified and justified                   |
| Methodology                  | TOST or one-sided CI                          |
| Forbidden                    | "Equivalent" without specifying the margin    |

## Wording rules

- **Absolute claims** ("eliminates wrinkles") require near-100% responder
  rate and are almost never acceptable for cosmetics.
- **Quantified claims** ("reduces wrinkle depth by 30%") require the exact
  figure to come from the study result with 95% CI.
- **Duration claims** ("24h hydration") require data at the claimed
  timepoint (24h post-application measurement).
- **Comparative claims** ("better than Brand X") require a head-to-head
  RCT with the named comparator.

## Risk levels

| Level  | Examples                                | Consequence               |
|--------|------------------------------------------|---------------------------|
| Low    | "Moisturises", "leaves skin soft"        | Self-declaration, basic study |
| Medium | "Reduces wrinkles in 28 days"            | Instrumental study + stats |
| High   | "Hypoallergenic", "clinically proven"    | Full clinical study + dermatologist + multiplicity |
